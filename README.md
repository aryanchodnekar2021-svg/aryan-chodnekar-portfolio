Welcome to the repository for my personal portfolio website. This project showcases my academic journey as a **Computer Engineering student at Mumbai University**, along with my certifications, technical skills, and commercial job simulations.

The site is built with a focus on modern, interactive UI design, featuring a "Cyber/Dark" aesthetic with 3D elements and smooth animations.

## ✨ Key Features

* **3D Holographic Portrait:** An interactive 3D tilt effect on the profile image that tracks mouse movement.
* **Custom Cursor:** A glowing, trailing cursor that adapts when hovering over clickable elements.
* **Animated Background:** A dynamic particle system and floating gradients for a depth-filled backdrop.
* **Responsive Design:** Fully optimized for all devices, including a stacked navigation layout for mobile users.
* **Glassmorphism:** Modern frosted glass effects on the navigation bar and cards.
* **Scroll Animations:** Elements fade in and slide up as you scroll down the page.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, Grid), JavaScript (ES6+).
* **Icons:** FontAwesome 6.4.0.
* **Fonts:** Inter (Google Fonts).
